# BACKLOG — черга автономної роботи

Черга для скіла `auto-work` (`.claude/skills/auto-work/SKILL.md`). Агент бере згори до
трьох пунктів, які не конфліктують між собою, і веде кожен у власній гілці-worktree
повним циклом з CLAUDE.md (propose → spec-reviewer → apply → verify → diff-reviewer).
Готові гілки вливаються по одній (`merge --squash` → `verify` → commit), далі зміни
перевіряються на емуляторі (`smoke-runner`), правляться за побаченим і аж тоді
архівуються; пункт відмічається `[x]` з рядком результату. Запуск — вручну (`/auto-work`
у будь-якій сесії) або сам собою (scheduled task `auto-work`, працює поки відкритий
застосунок).

Порядок у списку — це пріоритет, але сусідні пункти можуть піти в одну «хвилю»
паралельно. Не паралеляться (і це навмисно): міграції БД, зміни `package.json`,
нативні зміни (`app.json`, `plugins/`, `modules/`) і два пункти в одному capability.

Власник редагує цей файл вільно: додає, переставляє, уточнює. Порядок = пріоритет.
Пункт з позначкою `[?]` заблоковано питанням у розділі «Питання» — відповідь пишеться
просто під питанням, наступний запуск її підхопить і зніме позначку.

Джерело задумів — `docs/tech-task.md` §5; терміни — строго з `docs/glossary.md`.
`git push` агент не робить ніколи; публікація — рішення власника.
